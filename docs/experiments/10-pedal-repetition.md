# ペダルを踏んだままの同音連打（fs = 48 kHz）

ダンパーペダルを踏んだまま同じ鍵を 125〜250 ms 間隔で連打すると、鍵によってはその鍵の音程と違う響きが目立つ、という指摘の検査と対策。

## 検査方法（`engine/src/bin/repeat.rs`）

```
cd engine
cargo run --release --bin repeat -- scan              # 全 88 鍵 × {125, 180, 250} ms
cargo run --release --bin repeat -- key 61 125        # 1 鍵の成分一覧
cargo run --release --bin repeat -- wav out.wav 61 125  # 試聴用
```

* ペダルを踏み、強さ 0.7 で 8 回打鍵する。打鍵間隔には ±8 % のゆらぎを入れる（サンプル精度で等間隔に打つと、連打の周波数の整数倍にある成分だけが強め合い、人の演奏では起きない結果になる）。
* 最後の打鍵の 0.2 秒後から 0.68 秒間のスペクトル（A 特性）のピークを、「その鍵の成分」と「それ以外（foreign）」に分ける。その鍵の成分とは、剛性弦の部分音列 `n f0 √(1 + B n²)` の近く（±(12 + 0.6 n) セント）にあるもの、または、その鍵をペダルなしで 1 回だけ弾いた音にもはっきり含まれる成分。
* 指標 foreign [dB] = foreign 成分のパワーの和 ÷ その鍵の成分のパワーの和。3 つの間隔のうち最悪値を鍵の値とする。

## 原因

打鍵機構や弦モデルの再打鍵処理ではなく、ペダルで開放された**打鍵していない弦**の共鳴だった（全弦共鳴を切ると foreign 成分は消える）。

1. **響板の共振と同じ高さの弦が鳴り続ける。** 打鍵のたびに駒は響板の各モードの周波数でしばらく揺れ（低次モードの T60 は 0.1〜0.3 秒）、ちょうどその高さに調律された開放弦を共振で駆動する。弦は数秒かけて減衰するので、連打すると打鍵ごとに積み上がる。136〜156 Hz（C#3〜D#3）、195 Hz、394 Hz、697 Hz、1166 Hz、1389 Hz など、どの鍵を弾いても同じ高さが鳴っていた。特に低音駒の端では 140 Hz のモードの駒コンダクタンスが 0.021 s/kg（モード質量 1 kg、インピーダンス 48 kg/s）と、他の駒位置・モード（0.005〜0.009 s/kg）の 3〜4 倍あり、ペダル時に駒へ載る弦全体のインピーダンス（低音駒で約 150 kg/s）のほうが大きい。このためモードに入ったエネルギーの大半が弦に移っていた。
2. **駒の上で隣り合う弦が鳴る。** 同じ駒領域の弦はすべて 2 つの駒点を共有しているので、ある弦が駒を動かすと領域内の全弦がその動きをそのまま受ける。C#4 を連打すると C4 の弦が −15 dB で鳴る、といった半音違いの響きはこれによる。

現象そのもの（ペダル時に他の弦が鳴る、響板の共振に乗った弦が鳴りやすい）は実物のピアノにもあるが、強さはモデルの単純化（駒点の共有、平板の解が与える低次モードの動きやすさ）で誇張されていたと判断した。

## 対策

* `soundboard.rs` `G_CAP = 4e-3 s/kg`: 1 つのモードが共振時に駒点へ見せるコンダクタンスの上限（250 kg/s。グランドピアノの駒で測られるインピーダンスの下限程度）。超えるモードは駒との結合だけを弱める（形・放射・減衰は同じ）。対象は 465 モード中 10 個で、140 Hz が ×0.44、ほかは ×0.68〜0.99。
* `engine.rs` `SYMPATHETIC_LEVER = 0.35`: 打鍵されていない（共鳴しているだけの）弦と駒の結合を、打鍵された弦の 0.35 倍にする。打鍵すると 1 に戻り、鍵を離したあと弦のエネルギーが打鍵後の最大値から 40 dB 下がると、0.4 秒の時定数で 0.35 に戻る（ペダルを踏みっぱなしで鍵を順に弾いても、前に弾いた鍵の弦が強く結合したまま残らない）。結合は両方向に同じ比で弱めるので受動性は保たれる。
* 音量補正テーブル（`data/leveling.bin`）を作り直した。
